# Laminário 6F — Atualização Final

Extraia o ZIP. Faça upload do **conteúdo** da pasta `laminario-main/` para a raiz do repositório, incluindo `index.html`, `p1.html`, `p2.html`, `final.html` e a pasta `assets/`.

## Resumo do projeto

- **P1**: 7 patologias, 24 microfotografias.
- **P2**: 9 patologias, 41 microfotografias.
- **Final**: 9 patologias, 51 microfotografias.

## Processamento das imagens

As novas microfotografias foram convertidas para WebP 2000 × 2000 px preservando a transparência. As miniaturas também são WebP, em 240 × 240 px. A aba Final mantém o mesmo CSS de miniaturas usado na P1/P2, inclusive no celular.
